# Green House · ระบบแจ้งค่าเช่าหอพัก

- **บิลค่าเช่า** — เลือกเดือน กรอกเลขมิเตอร์ล่าสุดของแต่ละห้อง (บันทึกอัตโนมัติเมื่อกด Enter / ออกจากช่อง)
  ระบบดึงเลขมิเตอร์ครั้งก่อนจากเดือนก่อนหน้าให้เอง แล้วคำนวณ `หน่วย × ค่าไฟ/หน่วย + ค่าน้ำเหมา + ค่าห้อง + ค่าใช้จ่ายเพิ่มเติมทุกรายการ`
- **ออกบิล** — แก้ไขรายบิล (เพิ่ม/ลบค่าใช้จ่ายเพิ่มเติมได้หลายรายการ เช่น ค่าปรับ ค่าซ่อม, สถานะชำระ) แล้วดาวน์โหลดเป็น **PDF** หรือ **JPG** (บนมือถือที่รองรับมีปุ่มแชร์รูปไปยัง LINE ได้)
- **ตารางสรุปเดือนนี้** — ตารางทุกห้องในภาพเดียว ส่งออกเป็น JPG / PDF
- **ห้องพัก** — เพิ่ม/แก้ไข/ลบ เลขห้อง ผู้เช่า ค่าเช่า เลขมิเตอร์เริ่มต้น
- **ตั้งค่า** — ค่าไฟต่อหน่วย (เริ่มต้น 8 บาท), ค่าน้ำเหมา (เริ่มต้น 100 บาท),
  ค่าใช้จ่ายเพิ่มเติมประจำเดือน (เช่น ค่าส่วนกลาง ค่าขยะ — ใส่ในบิลใหม่ทุกห้องอัตโนมัติ), วันครบกำหนดชำระ, ชื่อ/ที่อยู่/ช่องทางชำระเงินบนบิล
  บิลที่บันทึกแล้วจะเก็บอัตรา ณ วันที่บันทึกไว้ เปลี่ยนอัตราภายหลังไม่กระทบบิลเก่า

## ใช้งาน

ต้องใช้ Node.js 22.13 ขึ้นไป (ใช้ SQLite ที่มากับ Node)

```bash
npm install
npm run build
npm start          # เปิด http://localhost:3001
```

มือถือ/แท็บเล็ตที่อยู่ Wi‑Fi เดียวกัน เปิด `http://<IP เครื่องนี้>:3001`
(ดู IP บน Mac: `ipconfig getifaddr en0`)

พัฒนา: `npm run dev` (API :3001 + Vite :5173)

ข้อมูลเก็บที่ `data/greenhouse.db` — สำรองไฟล์นี้ไฟล์เดียวพอ
